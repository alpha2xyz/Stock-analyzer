# بوت تنبيهات الأسهم الأمريكية

بوت بايثون يشتغل على الجوال عن طريق Termux، يفحص السوق الأمريكي بشكل دوري،
ولما سهم يحقق شروط معينة يرسل تنبيه على تيليجرام.

مشروع مستقل بالكامل، ما له أي ارتباط بأي مشروع ثاني.

## المرحلة 1 — خطوة بخطوة

### 1. سوّي بوت في تيليجرام

في تيليجرام، ابحث عن `@BotFather` وافتح المحادثة معه، ثم:

1. أرسل له: `/newbot`
2. بيطلب منك اسم للبوت (أي اسم تبيه، مثلاً `تنبيهات الأسهم`)
3. بيطلب منك username للبوت، لازم ينتهي بـ `bot` (مثلاً `my_stock_alert_bot`)
4. بيعطيك في الأخير نص طويل شكله كذا:
   `7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

هذا اسمه **التوكن (token)** — يعني كلمة السر حق البوت. **لا تعطيه أي أحد.**

### 2. حمّل المشروع على الجوال

في Termux:

```bash
pkg install git python
git clone https://github.com/alpha2xyz/stock-analyzer.git
cd stock-analyzer
```

> ملاحظة: المكتبات المطلوبة في هذه المرحلة **صفر** — الكود يستخدم أدوات
> بايثون الأساسية فقط، ما يحتاج أي `pip install`.

### 3. جهّز ملف الإعدادات

```bash
cp config.example.json config.json
nano config.json
```

حط التوكن اللي أعطاك إياه BotFather بين علامتي التنصيص:

```json
{
  "telegram_bot_token": "7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
  "telegram_chat_id": ""
}
```

للحفظ في nano: اضغط `Ctrl+O` ثم `Enter` ثم `Ctrl+X`.

> ملف `config.json` **ما يُرفع على GitHub** — محمي في `.gitignore`،
> عشان التوكن يبقى على جوالك بس.

### 4. اعرف رقم المحادثة حقك (chat_id)

البوت يحتاج يعرف لمين يرسل. سوِّ التالي:

1. افتح تيليجرام، ادخل على البوت اللي سويته، وأرسل له أي كلمة (مثلاً `مرحبا`)
2. رجّع لـ Termux وشغّل:

```bash
python bot.py chatid
```

بيطلع لك رقم مثل:

```
chat_id = 123456789   (اسمك)
```

انسخ الرقم وحطه في `config.json` في خانة `telegram_chat_id`.

### 5. شغّل البوت

```bash
python bot.py
```

المفروض توصلك رسالة على تيليجرام فيها الوقت ورقم المرحلة، ويطلع لك في
Termux: `تم إرسال الرسالة بنجاح.`

## المرحلة 2 — ربط Finnhub

### 1. سجّل حساب مجاني

ادخل على [finnhub.io](https://finnhub.io) وسجّل حساب مجاني. بعد التسجيل
بيعطيك **API key** — نص طويل شكله كذا:

```
d9svm11r01qqd5j2t430d9svm11r01qqd5j2t43g
```

هذا المفتاح **خاص فيك**، لا تعطيه أحد ولا تحطه في أي ملف يُرفع على GitHub.

### 2. حطّه في ملف الإعدادات

```bash
nano config.json
```

عبّي الحقل الثالث:

```json
{
  "telegram_bot_token": "...",
  "telegram_chat_id": "...",
  "finnhub_api_key": "حط المفتاح هنا"
}
```

### 3. جرّب

```bash
python bot.py price AAPL
```

المفروض توصلك رسالة على تيليجرام فيها سعر السهم والتغيّر وأعلى وأقل سعر
اليوم وإغلاق أمس. جرّب أي رمز أمريكي: `TSLA`، `NVDA`، `MSFT`.

## وش تغطيه الباقة المجانية من Finnhub

**هذا الجدول مبني على اختبار فعلي للمفتاح بتاريخ 2026-08-10، مو على كلام
الموقع.** مهم تقرأه قبل المرحلة 3، لأنه يحدد وش نقدر نبنيه ووش لا.

### الحد الأقصى للطلبات

**60 طلب في الدقيقة.** الرقم مقروء مباشرة من رد Finnhub نفسه (ترويسة
`x-ratelimit-limit`)، ويتجدد كل دقيقة.

> **وش يعني هذا للمرحلة 3:** فحص 100 سهم يحتاج طلبين لكل سهم على الأقل
> (السعر + بيانات الشركة) = 200 طلب ≈ **3-4 دقائق للفحصة الوحدة**. يعني
> الفحص الدوري ما يقدر يصير كل دقيقة، ولازم نحسب له وقت.

### الشي المتاح مجاناً ✅

| البيانات | من وين | يخدم أي شرط |
|---|---|---|
| السعر الحالي وأعلى/أقل اليوم وإغلاق أمس | `quote` | التنبيه نفسه |
| القيمة السوقية | `profile2` | **شرط 1** (بين 40 و 60 مليون) |
| عدد الأسهم الحرة (Float) | `profile2` → `floatingShare` | **شرط 2** (فوق 500,000) |
| متوسط حجم التداول (10 أيام و 3 شهور) | `metric` | خط الأساس لـ **شرط 3** |
| قائمة كل الأسهم الأمريكية | `stock/symbol` | تجهيز قائمة الفحص |

> **انتبه:** القيمة السوقية والفلوت **بالمليون**، مو بالوحدة. آبل ترجع
> `4572794` يعني 4.57 تريليون دولار. فشرط "بين 40 و 60 مليون دولار" معناه
> الرقم بين **40 و 60** بالضبط.

### الشي المحجوب عن الباقة المجانية ❌

| البيانات | الرد | وش يعطّل |
|---|---|---|
| البيانات التاريخية (شموع OHLC) — `stock/candle` | `403 You don't have access` | **حساب ATR** (المرحلة 4)، و **VWAP** (شرط 4)، وحجم تداول اليوم |

**النتيجة الصريحة:** من شروط الفلترة الأربعة، **اثنين جاهزين** (القيمة
السوقية والفلوت)، **وواحد ناقص** (شرط 3 — عندنا المتوسط بس ما عندنا حجم
اليوم)، **وواحد مو ممكن** (شرط 4 — VWAP يحتاج بيانات داخل اليوم). وكذلك
**وقف الخسارة بـ ATR في المرحلة 4 مو ممكن** بالباقة المجانية.

## المصدر الثاني: Twelve Data — يغطي الناقص

بعد ما طلع النقص فوق، انبحث عن مصدر مجاني ثاني يغطيه. **Twelve Data يغطيه**،
واختُبر بمفتاح باقة مجانية **حقيقية** بتاريخ ٢٠٢٦-٠٨-١٠:

| النقطة | الحالة على الباقة المجانية | تعطي |
|---|---|---|
| `quote` | ✅ متاح | السعر + **حجم اليوم** + **متوسط الحجم** — كلهم في طلب واحد |
| `vwap` | ✅ متاح | VWAP يومي **و داخل اليوم** (`5min`) |
| `atr` | ✅ متاح | ATR **محسوب جاهز**، ما نحسبه بأنفسنا |
| `time_series` | ✅ متاح | شموع تاريخية بالحجم |
| `statistics` | ❌ **محجوب — 403** | القيمة السوقية والفلوت — للباقات المدفوعة فقط |

> **درس تكرر مرتين في نفس اليوم:** مفتاح `demo` التجريبي كان يفتح
> `statistics` عادي، والمفتاح المجاني الحقيقي رفضه بـ 403. **لا تثق بنتيجة
> مفتاح تجريبي — اختبر دايماً بالمفتاح اللي بيشتغل به البوت فعلاً.**

### الحد عند Twelve Data

**٨ أرصدة في الدقيقة، و ٨٠٠ في اليوم.** والأرصدة **تُحسب لكل رمز، مو لكل
طلب** — قرأناها من ترويسة `api-credits-request` في الرد: طلب واحد فيه ٣
رموز كلّف ٣ أرصدة.

**لكن التجميع (batch) يشتغل**: تقدر تحط عدة رموز في طلب واحد
(`symbol=AAPL,MSFT,TSLA`)، وهذا يوفّر من حد "٨ في الدقيقة" حتى لو ما وفّر
من الأرصدة.

### ليش لازم نستخدم المصدرين مع بعض

**ما في مصدر واحد يكفي.** كل واحد يغطي بالضبط اللي الثاني يحجبه:

| المطلوب | Finnhub | Twelve Data |
|---|---|---|
| شرط ١ — القيمة السوقية | ✅ | ❌ محجوب |
| شرط ٢ — الفلوت | ✅ | ❌ محجوب |
| شرط ٣ — قفزة الحجم | ❌ ناقص | ✅ |
| شرط ٤ — VWAP | ❌ | ✅ |
| ATR (المرحلة ٤) | ❌ | ✅ |

يعني: **Finnhub يبني القائمة، و Twelve Data يفحصها.**

### الميزانية اليومية — كم سهم نقدر نغطي

في ميزانيتين منفصلتين، وكل وحدة تجاوب على سؤال مختلف.

#### أ) بناء القائمة — Finnhub

**طلب واحد لكل سهم يكفي.** `profile2` يرجّع القيمة السوقية والفلوت مع
بعض، فشرط ١ و ٢ يتغطون بطلب واحد.

| المطلوب | الوقت |
|---|---|
| ١٠٠ سهم | أقل من دقيقتين |
| ١٬٠٠٠ سهم | ١٧ دقيقة |
| كل السوق الأمريكي (~١٠٬٠٠٠) | ~٢٫٨ ساعة |

الحد ٦٠ طلب/دقيقة = **٣٬٦٠٠ سهم في الساعة**. ترويسة الرد ما تبيّن أي حد
يومي، بس ما تأكدنا من ذلك رسمياً — ومو مشكلة عملياً لأننا نشغّله **مرة في
اليوم** (القيمة السوقية والفلوت ما يتغيرون كل ساعة).

#### ب) الفحص المتكرر — Twelve Data ← **هذا هو الحد الحقيقي**

٨٠٠ رصيد في اليوم. كل سهم في كل فحصة يكلف رصيد واحد (`quote`)، زائد رصيد
ثاني (`vwap`) **فقط** للأسهم اللي نجحت في شرط الحجم — وهذي قليلة.

ساعات السوق الأمريكي ٦٫٥ ساعة (٤:٣٠ عصراً – ١١:٠٠ ليلاً بتوقيت السعودية):

| حجم القائمة | تكلفة الفحصة | فحصات في اليوم | يعني فحص كل |
|---|---|---|---|
| **١٠ أسهم** | ~١١ رصيد | ~٧٠ | **٥ دقائق** |
| **٢٠ سهم** | ~٢٢ رصيد | ~٣٦ | **١١ دقيقة** |
| **٥٠ سهم** | ~٥٥ رصيد | ~١٤ | **٢٨ دقيقة** |
| **١٠٠ سهم** | ~١١٠ رصيد | ~٧ | **٥٦ دقيقة** |

**التوصية: ٢٠–٣٠ سهم.** فحص كل ١٠ دقائق تقريباً — سريع كفاية لقفزة حجم.
عند ١٠٠ سهم يصير الفحص كل ساعة، وهذا بطيء لتنبيه مبني على قفزة حجم؛ القفزة
بتخلص قبل ما نشوفها.

**ملاحظة:** حد الـ ٨ في الدقيقة ما يعطّل شي هنا — حتى قائمة ١٠٠ سهم تنفحص
في ١٤ دقيقة، وهي أصلاً تنفحص مرة كل ٥٦ دقيقة. **الحد اليومي (٨٠٠) هو
القيد، مو السرعة.**

**الخلاصة: شرط القيمة السوقية الضيّق (٤٠–٦٠ مليون) هو اللي يخلي الباقة
المجانية تكفي** — لأنه يخلي القائمة قصيرة.

## تشغيل البوت والتخاطب معه

### شغّله

في Termux على الجوال:

```bash
cd ~/stock-analyzer
setsid nohup ./run.sh >/dev/null 2>&1 </dev/null &
```

هذا يشغّل البوت **مع حارس** يعيد تشغيله تلقائياً لو مات — وهذا الجوال يقتل
العمليات الطويلة أحياناً. المفروض توصلك رسالة "البوت اشتغل ✅" على تيليجرام.

### أوامره (اكتبها في محادثة البوت)

| الأمر | وش يسوي |
|---|---|
| `/help` | يعرض الأوامر |
| `/status` | البوت شغّال؟ السوق مفتوح؟ التوقيتين |
| `/price AAPL` | سعر أي سهم أمريكي الحين |
| `/refresh` | يبني قائمة المراقبة من السوق الأمريكي كله |
| `/list` | يعرض قائمة المراقبة |
| `/scan` | فحص فوري الحين |
| `/mute` | يوقف التنبيهات مؤقتاً — **البوت يضل شغّال** |
| `/unmute` | يرجّع التنبيهات |

كل هذي موجودة في **زر القائمة** داخل المحادثة، ما تحتاج تحفظها.

### أول مرة: ابنِ القائمة

```
/refresh
```

يمشي على السوق الأمريكي كله ويطلّع الأسهم اللي قيمتها السوقية بين ٤٠ و ٦٠
مليون وفلوتها فوق ٥٠٠ ألف. **ياخذ ساعة ونص تقريباً** ويخبرك بالتقدم، وتقدر
تستخدم باقي الأوامر خلاله. بعدها البوت يفحصهم تلقائياً كل ١٥ دقيقة وقت السوق.

### متى يشتغل

| | متى |
|---|---|
| **يسمع أوامرك** | ٢٤ ساعة — مجاني، ما يصرف أرصدة |
| **يفحص الأسهم** | وقت السوق الأمريكي بس (٤:٣٠ عصراً – ١١ ليلاً بتوقيتنا) |

**ليش يسمع ٢٤ ساعة؟** لأنك لو أرسلت له `/status` الظهر وما رد، ما بتعرف هل
هو نايم عادي ولا ميت. البوت الصامت والبوت الميت شكلهم واحد.

### وقّفه

```bash
pkill -f "[r]un.sh" && pkill -f "[b]ot.py run"
```

> **انتبه للأقواس `[r]`** — بدونها الأمر يطابق نفسه ويقتل جلستك أنت.

### شوف السجل

```bash
tail -20 ~/stock-analyzer/bot.log
```
